### Append-Only Stream CDC Practice

- Created `staging_table` as the source/staging table.
- Created `prod_table` as the production/target table.
- Created an append-only Stream on `staging_table` using `APPEND_ONLY = TRUE`.
- Inserted records into `staging_table` and checked the Stream to view the captured INSERT changes.
- Checked the Stream offset to observe its position in the source table's change history.
- Used `METADATA$ACTION = 'INSERT'` to filter INSERT changes from the Stream.
- Consumed the Stream using an `INSERT INTO ... SELECT` DML operation and loaded the captured records into `prod_table`.
- Inserted additional records into the staging table and checked the Stream again.
- Updated a record in `staging_table` and observed the Stream behavior.
- Used the append-only Stream to practice INSERT-based CDC processing.

### Key Concept

An append-only Stream captures **INSERT changes only** from the source table. It is useful when the CDC process only needs newly inserted records and does not need UPDATE or DELETE tracking.
