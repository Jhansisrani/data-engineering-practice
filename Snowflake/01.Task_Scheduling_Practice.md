### Task Scheduling Practice

- Used the existing `LINEITEM` table as the source table.
- Created `DAILY_AGGREGATED_SUMMARY` as the result table.
- Created a scheduled Task to aggregate data from `LINEITEM` and insert the results into `DAILY_AGGREGATED_SUMMARY`.
- Used `SUM`, `COUNT`, and `GROUP BY` to create daily shipping-mode summaries.
- Practiced changing the Task schedule using a CRON expression.
- Created a second Task to process data from `DAILY_AGGREGATED_SUMMARY` into `ORDERS_BY_SHIPMODE`.
- Used a Task dependency (`AFTER DAILY_SALES_TASK1`) so the second Task runs after the first Task completes.
- Practiced suspending and resuming Tasks.
